# Makolo realistic synthetic demo world (2025–2026)

This dataset is **demo/beta data only**. It is not production data and must never be run automatically from WSGI, a release hook, a scheduler, or a production migration.

## Purpose

`seed_makolo_world` creates a deterministic synthetic Makolo world that looks lived-in from January 2025 through December 2026. It exists to exercise the mature web experience with history, present-day work and future possibilities instead of tiny `test event` fixtures.

The full profile creates, among other things:

- 100 synthetic Profiles with plausible names, professions, interests and voluntary `Open to` declarations;
- 30 synthetic Spaces, Teams and contextual Mandates;
- 20 geographic Places/Zones across the DRC and other African cities, plus Brussels;
- 420 Activities across events, training, workshops, community action and Services;
- 840 concrete Occurrences spread across 2025 and 2026;
- Capacity and Offers for real action paths;
- 800 Journeys with historical and current states;
- Commerce orders, sandbox Payments, Access rights, credentials and historical AccessUse where applicable;
- 360 Opportunities across all canonical kinds: jobs, internships, scholarships, education, grants, competitions, programs, volunteering and other;
- requirements, sources, source checks and saves for Opportunities;
- 200 ActionNeeds with bilateral ActionProposals;
- 160 contextual Conversations with participations, Points and responses;
- 1,500 Contributions, all anchored to canonical Makolo contexts;
- more than 10,000 total records counted by the validator.

The seed is deterministic and designed to be rerunnable. Stable UUIDs and source/client references prevent the same world from multiplying on a second run.

## Synthetic identity and source policy

All Makolo people, Spaces, Activities and Opportunities generated by this seed are synthetic. Names are plausible but do not represent real people. Demo email addresses use the reserved `@makolo.demo` namespace.

Public URLs stored in descriptions or source-check notes are **calibration references only** (for example African Development Bank careers, African Union internships, Chevening, Erasmus Mundus, UN Volunteers, GITEX Africa and Mining Indaba). They help the synthetic world reflect the kinds of real opportunities and events seen in 2025–2026. A synthetic Opportunity never claims to be an official listing from those organizations.

Profile metadata contains deterministic generated-avatar URLs and Event metadata contains deterministic generated cover URLs. They remain remote presentation references; the seed performs no network fetch and therefore does not make database creation depend on a third-party media host.

## Passwords

No demo password is committed to Git. Supply it only at runtime through `MAKOLO_DEMO_PASSWORD` or `--demo-password`.

## Commands

Smoke dataset:

```bash
export MAKOLO_DEMO_PASSWORD='<demo-password>'
python manage.py seed_makolo_world --profile smoke --as-of 2026-09-16
python manage.py validate_makolo_world --profile smoke --as-of 2026-09-16
unset MAKOLO_DEMO_PASSWORD
```

Full dataset:

```bash
export MAKOLO_DEMO_PASSWORD='<demo-password>'
python manage.py seed_makolo_world --profile full --as-of 2026-09-16
python manage.py validate_makolo_world --profile full --as-of 2026-09-16
unset MAKOLO_DEMO_PASSWORD
```

## PythonAnywhere beta/test deployment

PythonAnywhere remains a beta/test environment unless canonical deployment documentation explicitly changes that status.

From a PythonAnywhere Bash console:

```bash
cd /home/makolo/makolo
source /home/makolo/.virtualenvs/makolo/bin/activate
set -a
source .env
set +a
git fetch origin
git checkout main
git pull --ff-only origin main
python -m pip install -r requirements.txt
python -m pip check
python manage.py check
python manage.py migrate --noinput
python manage.py migrate --check
python manage.py collectstatic --noinput
export MAKOLO_DEMO_PASSWORD='<demo-password>'
python manage.py seed_makolo_world --profile full --as-of 2026-09-16
python manage.py validate_makolo_world --profile full --as-of 2026-09-16
unset MAKOLO_DEMO_PASSWORD
```

Then reload `makolo.pythonanywhere.com` from the PythonAnywhere **Web** tab.

Do not add the seed command to the WSGI file or an automatic deployment hook.

## Validation contract

For `full`, `validate_makolo_world` checks minimum volumes including:

- at least 100 synthetic users;
- 30 Spaces;
- 400 Activities;
- 800 Occurrences;
- 300 Opportunities;
- 700 Journeys;
- 150 Conversations;
- 1,400 contextual Contributions;
- all canonical Opportunity kinds represented;
- substantial 2025 history and future Occurrences after the reference date;
- at least 10,000 counted demo-world records overall.

The smoke profile is used by the targeted automated test to verify idempotence before the large profile is used manually in beta.
