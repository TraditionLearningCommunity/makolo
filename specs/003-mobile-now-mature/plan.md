## Design

1. Add a lane-local `NowSelector` that consumes `StoredProjection` and produces:
   - ordered `NowSituationPresentation` values;
   - shared `MakoloSurfacePresentation`.
2. Replace generic `ProjectionScreen` rendering with a dedicated stateful Now composition.
3. Root composition:
   - dominant first situation;
   - secondary situations visually quieter;
   - calm success when known empty;
   - no dashboard/grid inflation.
4. N2:
   - selection is local UI state only;
   - Compact replaces field with focus;
   - Wide uses `MakoloAdaptiveSplit` at `MakoloLayout.nowFocusSplitMinWidth`;
   - back closes N2 and restores the field.
5. Owner handoff:
   - only when an existing canonical route is known from the structured source;
   - otherwise no invented CTA.
6. Keep runtime source `repository.watchNow()` unchanged.
